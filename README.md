# 🚀 Lancer – Connect Freelancers and Recruiters Seamlessly

**Lancer** is a full-stack platform designed to streamline hiring, collaboration, and project management between **recruiters** and **freelancers**. With a unified login system, intuitive UI, and powerful tools, Lancer empowers users to act as both talent seekers and service providers in one cohesive ecosystem.

---

## 🌟 Features

### 🧑‍💼 Freelancer Side
- **Personalized Profiles** – Add bio, portfolio projects, and skill tags.
- **Job Search** – Filter and apply to recruiter-posted opportunities.
- **Messaging System** – Communicate directly with recruiters.
- **News & Job Updates** – Access job market trends and announcements.

### 🧑‍💼 Recruiter Side
- **Post Jobs & Updates** – Reach out to targeted freelancers.
- **Advanced Search** – Filter by skill, rating, badge, or location.
- **Messaging Dashboard** – Central hub to manage all freelancer communication.

## 🚧 Installation

### 1. Clone the repo
```bash
git clone https://github.com/yourusername/lancer.git
cd lancer
```

2. Install dependencies
   
# Frontend
cd client
npm install

# Backend
cd ../server
npm install


3. Start the development server

# Backend
npm run dev

# Frontend (in separate terminal)
cd ../client
npm start
